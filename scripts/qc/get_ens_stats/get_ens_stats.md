# Get Ensemble Stats

This script calculates the minimum, maximum, mean, and standard deviation for each dataset contained within the input Intake-ESM catalog `input_catalog` and outputs a csv file `output_file` with the results. It will, by default, calculate the stats for each unique entry in the catalog. However, this behavior can be customized to concatenate over one or more columns if, e.g., your datasets are chunked into smaller time ranges. The optional `--config` file is a yaml that contains various options, and can include values for `input_catalog` and `output_file` as well. If `input_catalog` and `output_file` are supplied in the command line those values will always take precedence over the configuration file values.

The main script is `get_ens_stats.py`.
```
$ python get_ens_stats.py --help
usage: get_ens_stats.py [-h] [--config CONFIG] [input_catalog] [output_file]

Calculate summary statistics for datasets found in an intake-esm catalog.

positional arguments:
  input_catalog    Intake-ESM catalog used to find datasets.
  output_file      CSV file to write outputs to.

options:
  -h, --help       show this help message and exit
  --config CONFIG  Config yaml with additional configuration options.
```

The configuration file contains additional options:
- `variable_column`: The column that stores the variable id. Defaults to `variable_id`.
- `member_column`: The column that stores the member id or variant label. Defaults to `member_id`.
- `concatenate_by`: Column(s) to concatenate over. For example, in GFDL standards in order to concatenate over the entire time range of the dataset we would use `time_range`.
- `ignore_columns`: Columns to ignore when grouping that are not concatenated over. For example, there could be multiple different entries for `standard_name` for the same `variable_id`.
- `group_by`: Additional columns to group by other than `variable_column` and `member_column`. By default, the script will group by all columns other than those in `concatenate_by` and `ignore_columns`.
- `filter_by`: list of `column: value` pairs to filter the catalog by before running the script.

See `example_config.yaml` for an example configuration file, and `example_output.csv` for the output generated by that file.
